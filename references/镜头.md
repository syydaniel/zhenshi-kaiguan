# 镜头：先设计，再写代码

第一版 skill 只让模型「写 3 行以内的分镜」。结果做出来的火车像玩具，主要原因在镜头上：光圈大得不存在，正侧面平拍，画面只有两层，车慢得没有任何后果。这一份讲镜头怎么定。

写代码之前，先交一份「镜头设计」，七个问题都要有数：

1. **镜头**：全画幅几毫米、光圈值、对焦几米。
2. **机位**：离地多高、离主体多远、和主体行进方向成几度。
3. **运动**：起幅、怎么动、落幅，各几秒。
4. **层次**：前景、中景、远景各放什么；哪两样东西观众知道大小。
5. **主体**：最大的时候占画面多大，前进方向留多少空。
6. **速度**：主体每秒几米，每秒横穿画面的几分之几；用哪两种手法表达；前景物几秒划过一次，避开哪个时刻。
7. **光**：太阳的方位和高度，什么东西被逆光打亮。

## 景深按真实相机来定

**光圈半径不许直接写一个数，由镜头算出来。** 场景按米建模。

```glsl
// 镜头参数：只改这三个数
const float FOVY     = 0.5637;   // 垂直视角（弧度）。0.5637 = 32.3°，16:9 下相当于全画幅 35 毫米
const float FNUM     = 5.6;      // 光圈值
const float SENSOR_H = 0.02025;  // 感光面高度（米）。出 16:9 的片子用 0.02025

float focalLen = 0.5 * SENSOR_H / tan(0.5 * FOVY);   // 焦距（米）
float lensR    = focalLen / (2.0 * FNUM);            // 光圈半径（米）= 焦距 ÷ 光圈值 ÷ 2
float zoom     = 1.0 / tan(0.5 * FOVY);              // 光线方向里乘在 fw 上的那个系数

// 每个采样里（uv.y 的范围是 -1 到 1）：
vec3  rd = normalize(uv.x*rt + uv.y*up + zoom*fw);
float focusDist = length(focusPoint - ro);           // 对焦在主体上
vec2  u  = lensR * sqrt((fi + .5)/fn) * vec2(cos(ang), sin(ang));
vec3  fp = ro + rd * (focusDist / dot(rd, fw));
ro += rt*u.x + up*u.y;   rd = normalize(fp - ro);
```

场景单位不是米的话，先定「每单位多少米」，把 `lensR` 除以它。

| 全画幅焦距 | 垂直视角（16:9） | `FOVY`（弧度） | f/2.8 的光圈半径 | f/5.6 | f/8 |
|---|---|---|---|---|---|
| 24 毫米 | 45.7° | 0.798 | 0.0043 米 | 0.0021 | 0.0015 |
| 35 毫米 | 32.3° | 0.564 | 0.0063 | 0.0031 | 0.0022 |
| 50 毫米 | 22.9° | 0.400 | 0.0089 | 0.0045 | 0.0031 |
| 85 毫米 | 13.6° | 0.237 | 0.0152 | 0.0076 | 0.0053 |
| 135 毫米 | 8.6° | 0.150 | 0.0241 | 0.0121 | 0.0084 |

**渲之前先把镜头打印出来**：`node lens.mjs --mm 35 --f 5.6 --focus 19 --near 4`。它会报焦距、口径、超焦距、景深的近端和远端、背景和前景各虚多少像素，并指出不合理的地方。

三条判断线：

- 光圈值小于 1.4 一律不许。
- 对焦距离已经超过超焦距，背景就一定是清楚的。这时背景还虚了 3 像素以上，一定是写错了。
- 口径不要超过人眼瞳孔（约 4.6 毫米）的 8 倍。口径放大多少倍，观众就倾向于把场景看小多少倍。那列火车的口径是 80 毫米，17 倍。

**什么题材用多大光圈**

| 题材 | 镜头和光圈 | 说明 |
|---|---|---|
| 十米以上的大东西：火车、桥、楼、山、整条街 | 24 到 50 毫米，f/5.6 到 f/11 | 全幅清楚。层次靠空气、光和遮挡，不靠虚化 |
| 大东西，但想把它从背景里摘出来 | 85 到 135 毫米，退到 30 到 100 米外，f/2.8 到 f/5.6 | 虚化主要落在近处划过的前景上 |
| 人物中景、近景（2 到 5 米） | 35 到 85 毫米，f/2 到 f/4 | |
| 桌面静物、小物件（0.3 到 1 米） | 50 到 100 毫米，f/2.8 到 f/8 | 东西本来就小、就近，浅景深是如实的 |
| 故意做微缩感 | 口径开到瞳孔的几十倍，俯拍，拉高饱和度 | 不想要微缩感，就避开这三样同时出现 |

「景深」这个开关打开以后，变化可能很小，尤其是广角拍大场景。**这是对的，不要为了让它看得出来去放大光圈。** 想要明显的虚化，换长焦退远拍，或者在离镜头一两米的地方放前景。

## 机位、焦距和运动

- **机位高度**：平视最中性；仰拍显得高大有力，还能把主体衬在天空上；俯拍交代地形，但会压低气势，并且让迎面来的快速运动显得慢。拍车辆，机位放在离地 0.3 到 1.5 米。
- **角度**：和主体成 30 到 45 度，露出两个以上的面，才有体积。**不要正侧面平拍**，那样桥是一条水平线，车沿着画面平移，像摆在架子上的模型。
- **焦距**：透视只取决于机位。广角凑近拍，纵深被拉开，朝镜头来的东西变大得快，显得猛；长焦退远拍，空间被压扁，显得疏离，迎面来的车半天不见变大。
- **运动**：只做一种，并且要有理由。推是加张力，拉是露出环境，摇是跟随或揭示，移和跟是让机位真的在场景里走。推拉、横移、升降会带出视差和纵深；摇和变焦不会。
- **机位要像真的有人在拍**：三脚架、轨道车、跟拍车、摇臂、无人机到得了的地方。

**一个 5 到 10 秒的单镜头怎么排**（以 8 秒为例）

| 时间 | 做什么 |
|---|---|
| 0 到 1 秒，起幅 | 一幅站得住的画面，镜头不动或只有极小的呼吸。主体还没到，或者只露一点预告（树梢后面的烟、铁轨上的反光） |
| 1 到 6 秒，运动 | 只做一种运动，缓起、匀速、缓停 |
| 6 到 8 秒，落幅 | 停在第二幅站得住的画面上，里面有一样开头没有的东西（主体的另一面、露出来的太阳、远去的车尾） |

运动过程中，主体待在画面的同一块地方，观众的眼睛不用满画面找。

**规格表里写的主体大小是硬指标。** 中途改了机位（放低、退远），就同时改焦距把主体的大小补回来，不许让它悄悄变小。第二版的第一次实测里，规格表写的是机车占画面高 36%，机位放低以后只剩 22%，这是不合格的。

**细长的前景不要横穿主体。** 电线、栏杆、树枝这类贯穿整个画面的细线，放在主体的上方或下方，不要从车头、车轮上横着切过去。

**构图**

- 一幅画面只有一个视觉中心。不放正中；地平线不把画面平分，竖线不居中。
- 运动的主体，前进方向一侧多留空。
- 主体最大的时候，高度占画面三分之一以上，或者宽度占一半以上。
- 让东西互相遮挡，不要一排等距站着。让轨道、路、桥在画面里成斜线，往纵深走，引到主体上。

## 怎么表达速度

觉得快，靠两样：**离镜头最近的东西有多近**，以及**每秒有多少样东西从镜头前过去**。空旷的地方、远处的山，开得再快也显得慢。

先把速度本身写对：火车跑起来是每秒 15 到 25 米。那列火车第二版是每秒 2.5 米。然后从下面挑两种手法。

| 手法 | 怎么做 | 目标量 |
|---|---|---|
| 近处的前景物划过 | 镜头跟着主体走，在离镜头 3 到 8 米处放一排东西（杆子、立柱、灌木）。分三层：2 到 6 米、15 到 40 米、几百米以外 | 一样东西横穿画面不超过 0.3 秒；每秒划过不超过 4 到 6 次，间距打乱两成 |
| 跟摇 | 机位固定，朝向每一刻对准主体同一个点，用每个采样自己的时刻算朝向，背景会自动拉成丝 | 背景每帧拖 30 到 60 像素（1080p）。背景里要有能拉成丝的东西 |
| 低机位、贴近、广角 | 机位离地 0.3 到 0.6 米，离主体侧面 2 到 5 米，24 到 35 毫米。地面要有能掠过的纹理 | |
| 迎面来，擦着镜头过去 | 机位在路线旁 2 到 4 米，和路线成 20 到 40 度，主体从 80 到 150 米外过来。擦过的瞬间可以接一个跟摇 | 主体最近时每秒横穿 0.7 到 1.5 个画面宽；低于 0.3 就显得慢 |
| 让速度有后果 | 烟贴着车顶往后躺；车头两侧卷起雪雾或尘土；桥面和栏杆小幅震动；影子从地上扫过 | 全部写成 `f(t − 到达时刻)` |
| 机身轻微抖动 | 给相机朝向加几个频率互不成整数比的正弦，幅度随主体接近而增大。用每个采样自己的时刻算，让它进入运动模糊 | 最近时 0.1 到 0.3 度，平时接近 0 |
| 明暗交替 | 低太阳穿过一排树或桥的桁架，影子一条条扫过车身 | 每秒不超过 6 次 |

快门用 180°（24 帧每秒时曝光 1/48 秒）。拖影长到 100 像素以上时，采样数提到 48 以上，否则会出一道道台阶。

速度上去以后，轮子的辐条本来就会糊成一片，这是对的。这时靠连杆的往复和轮缘上那一点高光来读出转动。

规则排列的东西（枕木、栏杆立柱）每秒掠过的次数超过帧率的一半，会像车轮倒转一样显得慢甚至往回走。让它们靠运动模糊糊成一片，或者把间距打乱。

**不要做的**：高机位俯拍迎面来的运动；正侧面、远距离、空背景；只靠主体自己动，镜头和环境都没有反应。

## 近处有东西从镜头前划过

近处的杆子、树干、桥头的桁架，用好了同时给三样东西：纵深（视差）、大小（观众知道电线杆多高）、速度（一根一根划过）。

那列火车第一版的杆子减分，是排法的问题：

- 镜头每秒只走 1.4 米，杆子横穿画面用了 3 秒左右。它不是「划过」，是「挡着」。
- 它被一个不存在的大光圈虚成了一条灰影，没有顶也没有脚，认不出是什么。
- 它在画面正中，正好压在车头上。

| 情况 | 排法 |
|---|---|
| 镜头相对杆子很快（每秒 10 米以上） | 当「划过」用。离镜头 3 到 8 米，横穿时间控制在 0.3 秒以内，靠运动模糊变虚 |
| 镜头相对杆子很慢（每秒 3 米以下） | 当边框用。放在画面最外侧五分之一以内，清楚，压暗成剪影，露出杆顶或杆脚 |
| 想要节奏 | 一排杆子，间距几十米，两三秒划过一次 |
| 想要揭示 | 让它先挡住主体，划开之后主体已经在画面里了 |

横穿时间 = 2 × 距离 × tan(水平视角 ÷ 2) ÷ 相对速度。

闭式场景可以把这件事排准：

1. 先定关键时刻：车头进画、离镜头最近、连杆最清楚的那一下。
2. 杆子的位置写成 `x_k = x0 + k * L`，解出每一根划过画面中线的时刻。
3. 选 `x0`，让关键时刻落在相邻两次划过的正中间。
4. 划过的那几帧，让杆子压在车厢上，不压在车头、动轮和驾驶室上。
5. 自检时把每次划过的前一帧、正中一帧、后一帧各渲一张，确认主体在正中那帧仍然认得出来。

## 出处

- Held、Cooper、O'Brien、Banks，《Using Blur to Affect Perceived Distance and Size》，ACM Transactions on Graphics，2010。口径放大 m 倍，等于把场景缩小 m 倍；画面里有观众知道大小的东西，会削弱这种缩小感。这篇读了全文。把它用到「17 倍」这么小的倍数上是外推，方向有论文支持，强度没有实验数据。
- Joseph V. Mascelli，《The Five C's of Cinematography》。机位、角度、构图、前景框、起幅落幅。这里用的是别人的详细摘要，没有读到原书。
- Bruce Block，《The Visual Story》。深空间和平空间。二手转述。
- Blain Brown，《Cinematography: Theory and Practice》。只读到目录、图注和一章样章。
- Phedon Papamichael（《极速车王》）、Claudio Miranda（《壮志凌云：独行侠》）的访谈；Tom Oseman 讲追逐戏速度感的文章；RED 讲快门角度的文章。
- 景深公式和视角换算来自维基百科的 Depth of field、Angle of view、Hyperfocal distance 等条目，表里的数字是重新算过的。
- 表里带范围的目标量（每帧拖多少像素、几秒划过一次、抖动多少度）是由几个真实例子归纳的建议值，不是测出来的阈值。
