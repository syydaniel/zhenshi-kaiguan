# 七个开关，加一个「空气」

着色器里用一个 `lvl` 变量控制，页面用 `?level=N` 固定某一级。每一级都在上一级的基础上加东西，所以对比图里能看出这一项到底贡献了什么。

**编号要先定清楚。** 室外场景在软阴影和景深之间多一级「空气」，后面三级的编号各加一：

| 开关 | 室内（`index.html`） | 室外（`lake.html`、`mech.html`） |
|---|---|---|
| 平涂 | 0 | 0 |
| 直射光和硬阴影 | 1 | 1 |
| 程序化贴图 | 2 | 2 |
| 环境光和反射 | 3 | 3 |
| 软阴影和接触阴影 | 4 | 4 |
| 空气 | 没有 | 5 |
| 景深 | 5 | 6 |
| 运动模糊 | 6 | 7 |
| 色调映射和颗粒 | 7 | 8 |

下面的小标题用的是室内的编号。写室外场景时，着色器里的判断要按右边一列写（景深是 `lvl >= 6.`，色调映射是 `lvl >= 8.`），`NAMES` 也要有九个名字。

写的时候记住一条：**每个开关打开，画面要有一眼看得出的变化。** 看不出来，要么没写对，要么参数太保守。

景深是例外。广角拍十米以外的大东西，按真实镜头算，背景本来就不该虚。这时变化很小是对的，**不要为了让它看得出来去放大光圈**，那样整个场景会变成微缩模型。想看到虚化，在离镜头一两米的地方放前景，或者换长焦退远拍。

## 0 平涂

每种材质一个颜色，不算光照，直接输出 `alb`。它是对比的起点，要故意做得像剪纸或者示意图。
室外可以让它更有趣：`lake.html` 按高度分层上色加等高线，像一张地图。

## 1 直射光和硬阴影

- 一盏主光（太阳或者一扇窗）。漫反射 `max(dot(n, L), 0)`，再朝光源方向步进一次判断有没有被挡住（挡住就是 0）。
- 这一级**不要加环境光**（最多 0.01 到 0.03），让背光面几乎全黑。这样下一级打开环境光时对比才明显。
- **曝光系数**：从这一级起，后期之前统一乘一个小于 1 的数（示例里静物是 0.46，山湖 0.62，机甲城 0.70）。前面几级不做色调映射，不乘这个数会整片过曝。这个数按场景的亮度自己调，调到最亮的受光面刚好不发白。
- 让光有形状：窗框的影子、楼之间的光带。一整片均匀的光看不出「光从哪来」。
- 常见错误：阴影起点没有沿法线抬一点，表面全是黑斑（自阴影）。抬 0.01 到 0.1，按场景尺度定。

## 2 程序化贴图

没有图片，全部用噪声算。`material()` 里按材质编号分支，`lvl >= 2` 才进去。每个表面至少三样东西：

- **三种尺度的颜色变化**：大块的色差（低频噪声）、中等的纹理（木纹、岩层、楼的窗格）、细碎的脏点（高频噪声）。
- **法线起伏**：用噪声的差分把法线推歪一点，缝隙处推得多一些。
- **粗糙度变化**：同一块材质上有的地方亮、有的地方哑。
- 缝隙、底部、接触处变暗；边缘掉漆、生锈、有污渍。
- 细节要有密度。thousand-peaks 的制作手册里的原话是 "Empty smooth areas are a bug."
- 运动的物体，贴图坐标要跟着物体转（先把点变换到物体自己的坐标系再算噪声），否则纹理会在表面上滑。
- 常见错误：用 `fract(sin(dot(p, …)) * 43758.5453)` 做格点哈希，坐标一大就出条纹。格点哈希用整数运算（示例里的 `h21`）；`sin` 版本只留给屏幕像素抖动。

## 3 环境光和反射

- 环境光：按法线朝上还是朝下，在「天空的颜色」和「地面反弹的颜色」之间插值。背光面从全黑变成有颜色，这是这一级最大的变化。
- 天空或房间环境写成一个函数 `env(rd)`，没打中任何东西的光线、反射光线都查它。
- 反射：菲涅尔 `F = F0 + (1 - F0) * pow(1 - dot(n, v), 5)`，非金属 `F0 = 0.04`，金属用它自己的颜色。沿反射方向再步进一次（可以用更少的步数和简化的光照），粗糙的表面把反射结果往环境光上混。
- 高光：按粗糙度控制大小和强度。泛光和高光都要克制，金属的粗糙度别太低，否则出白条。
- 水面是这一级的受益大户：法线用几层移动的噪声，反射天空和山，斜着看反射更强，浅处透出水底颜色。

## 4 软阴影和接触阴影

- 软阴影：朝光源步进时记录 `min(k * h / t)`（`h` 是当前离最近表面的距离，`t` 是已经走的距离），得到半影。`k` 越大影子越硬。
- 接触阴影（环境光遮蔽）：沿法线取 4 到 5 个点，看「本来应该离表面这么远，实际更近」的差值。它只乘在环境光和反射上。
- 验收：物体和地面挨着的地方有一圈暗。没有这一圈，物体像后期贴上去的。

## （室外）空气

- 距离雾：`col = col * exp(-fo) + 雾色 * (1 - exp(-fo))`，密度随高度衰减。雾色朝太阳的方向偏暖，背着太阳偏蓝。
- 作用是把远近分出层次：远处的东西一层比一层淡。没有它，再大的山看着也像桌上的模型。
- 想要光柱：沿视线走十来步，每一步问一次「这里照得到太阳吗」。遮挡测试用一个粗略版的场景（只有大盒子），否则非常慢。
- 密度宁小勿大。第一版几乎都会写得太浓，把主体洗白。

## 5 景深

- 薄透镜：每个采样在光圈圆盘上取一个点当光线起点，光线都指向焦平面上的同一个点。圆盘上的点用螺旋（黄金角）分布，再用每像素的抖动旋转。
- **光圈半径不许直接写一个数。** 先定镜头（全画幅几毫米、光圈值），光圈半径 = 焦距 ÷ 光圈值 ÷ 2，场景按米建模。代码和对照表见 `镜头.md`。写之前跑一遍 `node lens.mjs --mm 35 --f 5.6 --focus 19 --near 4`，看它报的景深范围和虚化像素。
- 十米以外的大东西（火车、楼、山）用 24 到 50 毫米、f/5.6 到 f/11，全幅清楚。桌面上的小物件离镜头不到一米，浅景深是如实的。
- 焦点对在主体上，跟着主体走。
- 常见错误：照着感觉填一个 0.03、0.04 的光圈半径。那是口径六到八厘米的镜头，广角里不存在，画面会像移轴摄影拍的「小人国」。
- 验收：`lens.mjs` 没有报警；最近的前景和最远的背景各虚多少像素，和它算的对得上。

## 6 运动模糊

- 每个采样取不同的时刻：`t + (i + 抖动) / N * 快门时间`。180° 快门就是半帧的时长（24 帧每秒时是 1/48 秒）。
- 场景里要有动得快的东西才看得出来：弹跳的球、扇翅膀的鸟、近处掠过的水面、飘落的灰。
- 相机的位置和朝向也要用每个采样自己的时刻来算。这样镜头跟摇时主体清楚、背景拉成丝，镜头抖动也会进入模糊，而不是清晰的画面在抖。
- 运动本身怎么写（起步、跟随、重量、转动的东西怎么让人看出在转），见 `运动.md`。速度感怎么靠镜头和前景做出来，见 `镜头.md`。
- 拖影长到 100 像素以上时，采样数提到 48 以上，否则会出一道道台阶。
- 景深和运动模糊共用同一批采样，所以这两级的采样数要够（1080p 用 24 个上下）。

## 7 色调映射、调色、暗角、颗粒

顺序：曝光 → ACES 近似的色调曲线 → gamma → 一点 S 形对比 → 饱和度 → 暗部偏冷亮部偏暖 → 暗角 → 颗粒。

```glsl
col = col * (2.51 * col + .03) / (col * (2.43 * col + .59) + .14);   // ACES 近似
col = pow(clamp(col, 0., 1.), vec3(1. / 2.2));
col = mix(col, col * col * (3. - 2. * col), .5);                        // 对比
col *= 1. - .30 * dot(uv * .52, uv * .52);                              // 暗角
col += (hash(fragCoord + frame) - .5) * .035;                           // 颗粒
```

颗粒的种子是外壳传进来的 `FR`，它等于 `round(t * 24)`，也就是每秒换 24 次。按 24 帧出片时正好一帧一换；按 30 或 60 帧出片时相邻两帧可能用同一张颗粒，想避免就把 `harness.js` 里那个 24 改成你的帧率。

- 前面几级为了对比，只做 gamma，不做色调映射，所以高光会过曝，这是故意的。
- 这一级打开后画面应该更「像照片」：亮部不再是一片白，暗部有颜色倾向。

## 采样的骨架

所有示例的 `main()` 都是同一个结构：

```glsl
for (int i = 0; i < NS; i++) {
  像素内抖动（抗锯齿）
  if (lvl >= 运动模糊) 时间抖动
  if (lvl >= 景深) 光圈抖动
  acc += shade(ro, rd, t, lvl);
}
col = acc / NS;  然后做后期
```

对比擦除也在这里：`float lvl = fragCoord.x < W ? LB : LA;`，同一帧里左边是新级别、右边是旧级别。
